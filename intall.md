Для корректной работы форума для обсуждения компьютерных игр и игровой индустрии необходим установленный Node.js и СУБД MySQL. Процесс установки и настройки состоит из следующих шагов:
1. Установка необходимого программного обеспечения:
	Установить Node.js (версия 18.x или новее) с официального сайта.
	Установить MySQL (версия 8.0 или новее) или использовать сборку XAMPP / OpenServer для удобного запуска MySQL.
	Для редактирования кода рекомендуется использовать любой редактор, например, Visual Studio Code.
2. Развертывание проекта:
	Скачать или склонировать репозиторий форума с GitHub:
git clone https://github.com/Tunez666/forum.git
	Открыть терминал в папке проекта.
	Установить все зависимости, выполнив команду:
npm install
3. Настройка базы данных:
	Запустить MySQL (через XAMPP, OpenServer или встроенную службу).
	Открыть phpMyAdmin или любой другой клиент MySQL.
	Создать новую базу данных для форума (например, forum_db).
	Импортировать в созданную базу данных дамп структуры и начальных данных из файла database.sql (находится в корне проекта или в папке database/).
4. Настройка переменных окружения:
	В корне проекта создать файл .env 
	Указать параметры подключения к базе данных:
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=forum_db
DB_PORT=3306
	При необходимости указать порт для запуска сервера:
PORT=3000
5. Запуск приложения:
	В терминале в папке проекта выполнить команду запуска:
npm start или node app.js
	Для режима разработки с автоматической перезагрузкой:
npm run dev (если настроен nodemon)
	Открыть в браузере адрес: http://localhost:3000
	Проверка работоспособности:
	При успешном запуске в терминале появится сообщение:
Server is running on port 3000
	В браузере откроется главная страница форума.
После выполнения этих шагов форум для обсуждения компьютерных игр и игровой индустрии будет доступен для использования и дальнейшего тестирования.
